# Tetris AI - C语言实现

## 项目概述
基于C语言的俄罗斯方块AI控制器，能够根据当前游戏状态和下一个方块自动选择最佳旋转角度与放置位置。

## 文件结构

### 根目录
- `random_sequence.c` - 生成随机方块序列用于测试
- 版本文件：
    - `tetris_v1.c` - 初始版本实现
    - `tetris_v2.c` - 优化评估函数版本
    - `tetris_v3.c` - 最终优化版本

### Tetris文件夹 (v3模块化实现)
- `main.c` - 主程序入口，负责读取输入并执行AI决策
- 规则模块：
    - `rules.h`/`rules.c` - 定义游戏规则和评估函数
- 策略模块：
    - `strategy.h`/`strategy.c` - AI核心策略实现
        - `select_best_action` 函数
        - `suicide_place_piece` 函数
- 基础模块：
    - `tetris.h`/`tetris.c` - 游戏数据结构和方块形状初始化

## 核心功能

### 方块系统
- 支持7种标准方块类型：
    - I, T, O, J, L, S, Z
- 每种方块4种旋转状态

### AI策略
- 通过评估当前和下一回合状态选择最优操作
- 主要决策函数：
    - `select_best_action` - 选择最佳放置策略
    - `suicide_place_piece` - 超时时的应急放置策略

### 评估体系
使用多维度地形指标计算状态评分：
- 空洞数量
- 高度差异
- 行清除奖励
- 其他优化指标

## 策略特点
1. 多版本逐步优化评估函数
2. 模块化设计(v3)
3. 包含应急处理机制
4. 支持随机序列测试
